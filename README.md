# Cold Arc

A 90-day Winter Arc tracker. Installs to your phone, works offline, costs nothing to run.

**[suyash2906.github.io/COLD_ARC](https://suyash2906.github.io/COLD_ARC/)**

## Install it

Open the link in **Safari**, then Share -> **Add to Home Screen**.

It opens full-screen like a normal app, works with no signal, and keeps your data on the
device.

## Private by design

No account, no server. Everything stays on the phone. Use **More → Export everything** to
back it up.

## Development

```bash
npm install
npm run dev      # localhost:5173
npm test         # scoring + privacy tests
npm run build
```

Pushing to `main` deploys automatically.
